# Projeto — Auxiliar Administrativo na Prática

## 🎯 Objetivo

Simular uma rotina profissional de Auxiliar Administrativo, trabalhando com organização de documentos, cadastros, lançamento de informações, planilhas, controles, relatórios e rotinas financeiras.

O projeto foi estruturado para desenvolver competências encontradas em vagas reais de Auxiliar Administrativo, Assistente Administrativo e posições de entrada em áreas Financeiras/Administrativas.
